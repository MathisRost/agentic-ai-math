# Start prompt

Open this folder as the project and select GPT-6 Astra with xhigh reasoning
before sending the following prompt. Saving this file does not launch anything.

```text
Run the research experiment in this project. Read AGENTS.md, workflow.json,
instructions/coordinator.md, instructions/accounting.md and
common/problem_statement.md before dispatching agents.

Use gpt-6-astra with xhigh reasoning for yourself and every agent, with no
silent model substitution. Verify the model settings and token-accounting
capability first. If the model cannot be verified, stop and report it. If exact
per-agent token telemetry is unavailable, tell me before substantive research
and ask whether to continue with explicitly labelled estimates and NR fields.

Start from S0: for every prescribed lambda_0 > 0, seek one stationary, simple,
locally finite point process on R^3 with that intensity and exact FULL factorial
densities rho^(2)=a_2/D, rho^(3)=a_3/A and rho^(4)=a_4/V, simultaneously almost
everywhere on all nondegenerate configurations, for positive constants
independent of the configuration. Start with no upper diameter bound, no lower
distance/altitude cutoffs and no finite-fourth-moment assumption. Treat the
usual DVJ finite-moment class separately. Do not replace "=" by "~", approximate
identities or connected densities.

First dispatch two independent non-existence agents in fresh contexts. Have
a fresh reviewer audit their frozen proofs. Only a checked obstruction may
justify a coordinator-led restriction of the target, and only within its
actual scope. Version and explain every adopted adjustment; inform all roles.

Then run the four independent construction approaches with the same adopted
target and the labelled prior-work packet. Use one shared literature agent
and a coder only as needed. Give each construction approach four substantive
submissions total, with independent review: the initial attempt plus three
repairs. Weaker results are partial progress, not success.

After three unsuccessful reviewed submissions, an agent may ask me to approve
a precise change of statement, explaining what is lost and why it may help.
Do not enact that change without my explicit approval. Without approval, the
fourth attempt remains on the current target. Do not silently reset the four-
attempt allowance when a statement changes.

Freeze the sources, targets, submissions and reviews with hashes. Preserve all
versions. Keep separate contexts, all parent/partition contributions and exact
quantifiers. Save proofs, high-level reasoning and decision summaries (not raw
private chain-of-thought), review responses and remaining gaps. Record measured
input, cached-input, output, reasoning and total tokens per agent and turn
whenever available; keep estimates and unavailable fields separate.

Finish with an extensive mathematical report, exact target/version outcomes,
an account of what each approach did and did not prove, and a small per-agent
usage/cost table with its measurement limits. Do not edit the original project,
publish anything, or substitute numerical experiments for the existence proof.
```
