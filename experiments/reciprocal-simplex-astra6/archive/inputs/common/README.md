# Shared mathematical inputs

- `problem_statement.md`: immutable initial S0.
- `papers/INDEX.md`: published primary sources and page pointers.
- `dvj_context.md`: neutral historical/convention clarification.

No old research findings, review verdicts or simulation results are in this
common packet. At launch the coordinator copies these files into the new run
and records hashes. Later target versions live under that run's `statements/`.
Do not mistake the baseline S0 for a newer adopted target: each dispatch must
name the active statement path AND hash explicitly.

`../starting_information/` is a separate, labelled construction-only packet.
Initial non-existence agents may not read it.
